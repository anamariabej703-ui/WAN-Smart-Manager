Escenario de demostración

Esta red ficticia representa una oficina central conectada a dos sedes. En Topología puedes agregar equipos y crear enlaces seleccionando dos dispositivos. Los cambios se guardan en este navegador.

Consejo: comienza con direcciones y equipos ficticios. Esta herramienta todavía no aplica cambios en infraestructura real.

Funciones disponibles

Primera versión del proyecto.

✓ Calculadora IPv4 con máscara, red y broadcast
✓ Registro de dispositivos y enlaces
✓ Plantillas Cisco IOS y Huawei VRP
✓ Recomendaciones locales basadas en reglas
◷ IPv6 avanzado, SSH real e IA conectada: siguiente etapa

Flujo recomendado

Trabaja en este orden para diseñar una red.

01 · Define el rango de direcciones IP
02 · Registra dispositivos y enlaces
03 · Genera una plantilla para el fabricante
04 · Revisa advertencias y requerimientos

IP Planning · Calculadora IPv4

Ingresa una dirección IPv4 y su prefijo CIDR. Ejemplo: 192.168.10.0 /26.

Resultado

Presiona “Calcular subred” para ver los resultados.

Constructor de topología

Agrega dispositivos ficticios a tu escenario. Por ahora se muestran como una lista y un esquema visual simple.

Crear un enlace entre dispositivos

Elige los dos equipos que quieres conectar y define el tipo de enlace.

Enlaces registrados

Los dispositivos y enlaces se guardan en el almacenamiento local de este navegador. No se envían a internet.

Generador de configuraciones

Crea una plantilla de ejemplo. Revisa y adapta los comandos al modelo y versión exactos del equipo antes de utilizarlos.

Las plantillas son ejemplos educativos. No incluyen contraseñas ni se ejecutan sobre equipos.

Configuración generada

Selecciona “Generar plantilla”.

Asistente de redes

Este primer asistente funciona con reglas y respuestas locales; no es todavía un modelo de IA conectado. Puedes preguntarle sobre subnetting, VLAN, VPN, OSPF, BGP, seguridad o ancho de banda.

Recomendación

Escribe una pregunta y pulsa “Consultar asistente”.
Para tener IA generativa real más adelante, se deberá integrar un backend con una API segura. No pegues claves API, contraseñas ni datos confidenciales en esta página.

Requerimientos, ancho de banda y presupuesto

Registra una estimación inicial para una sede. Los costos son valores de ejemplo que puedes cambiar.

Resumen del proyecto

Completa los datos y calcula la estimación.
