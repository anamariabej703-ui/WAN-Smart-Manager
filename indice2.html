Escenario de demostración

Esta red representa una oficina central conectada a dos sedes. En Topología puedes agregar equipos y crear enlaces seleccionando dos dispositivos.

Consejo: comienza con direcciones y equipos ficticios. Esta herramienta no aplica cambios en infraestructura real ni transmite credenciales a servidores externos.

Funciones disponibles (Corte 3)

Versión v3.0 con soporte multimarca y ciberdefensa integrada.

✓ Calculadora IPv4 con validación estricta de octetos y clase
✓ Registro seguro de dispositivos (Sanitización XSS / Prompt Injection)
✓ Generación multimarca: Cisco, Huawei, Fortinet, MikroTik
✓ Módulo Ciberdefensa: Alerta de credenciales por defecto y servicios inseguros (Telnet/HTTP)
✓ Asistente de seguridad basado en políticas docs/politicas-ia.md

Flujo recomendado

Trabaja en este orden para diseñar una red.

01 · Define el rango de direcciones IP
02 · Registra dispositivos y enlaces
03 · Genera una plantilla para la marca deseada
04 · Audita la ciberdefensa y valida requerimientos

IP Planning · Calculadora IPv4

Ingresa una dirección IPv4 y su prefijo CIDR. Ejemplo: 192.168.10.0 /26.

Resultado

Presiona “Calcular subred” para ver los resultados.

Constructor de topología

Agrega dispositivos ficticios a tu escenario. (Valida entradas contra inyecciones y nombres peligrosos).

Crear un enlace entre dispositivos

Elige los dos equipos que quieres conectar y define el tipo de enlace.

Enlaces registrados

Los dispositivos y enlaces se guardan en el almacenamiento local de este navegador.

Generador de configuraciones multimarca + Ciberdefensa

Crea una plantilla de configuración para Cisco, Huawei, Fortinet o MikroTik. Aplica reglas de mínimo privilegio.

Las plantillas son ejemplos educativos. No incluyen contraseñas ni se ejecutan sobre equipos.

Configuración generada

Selecciona “Generar plantilla”.

Asistente de redes y Ciberdefensa Anti-IA
